# Problem Statement

Students and beginner cooks often want simple recipes without searching through long websites or videos. A small application can provide the ingredients and cooking steps in one place.

The aim of this project is to create a simple Python recipe and cooking application where users can search for recipes, view ingredients and instructions, and save their favourite recipes.

## Scope

The application contains a small collection of vegetarian recipes and provides basic searching, recipe display and favourites functionality.

## Target Users

- Students
- Beginner cooks
- People looking for quick vegetarian recipes

## High-Level Features

- Recipe selection
- Recipe search
- Ingredient display
- Cooking instructions
- Favourite recipes
- Simple GUI
- Basic error handling
